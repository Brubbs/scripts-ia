# Machine Learning Projects

Repositório dedicado ao desenvolvimento e à aplicação de algoritmos de **Machine Learning**, utilizando Python e bibliotecas do ecossistema de ciência de dados.

O objetivo é explorar diferentes técnicas de aprendizado de máquina, incluindo classificação, agrupamento (*clustering*) e análise de dados, por meio de projetos práticos.

## Projetos

### 1. Iris Dataset Analysis
**Arquivo:** `Analise_Iris1.py`

Análise exploratória do conjunto de dados Iris, explorando características das amostras e padrões presentes nos dados.

### 2. Decision Tree Classification
**Arquivo:** `Classification_Decision_Tree.py`

Implementação de um modelo de classificação utilizando árvores de decisão (*Decision Tree*), explorando o treinamento e a avaliação de modelos preditivos.

### 3. K-Means Clustering
**Arquivo:** `Clustering_KMeans_Modified.py`

Aplicação do algoritmo K-Means para agrupamento de dados (*unsupervised learning*), explorando a identificação de padrões e a formação de clusters.

### 4. Breast Cancer Classification – MLP
**Arquivo:** `MLP_Breast_Cancer_Classification.py`

Desenvolvimento de um modelo de classificação utilizando redes neurais artificiais, por meio do algoritmo MLP (*Multilayer Perceptron*), aplicado à identificação de tumores benignos e malignos.

### 5. Fraud Detection – Random Forest
**Arquivo:** `RandomForestClassifierFraudes.py`

Implementação de um modelo de classificação utilizando Random Forest para identificação de possíveis fraudes, explorando técnicas de aprendizado supervisionado.

## Tecnologias e ferramentas

- **Python**
- **Pandas** – Manipulação e análise de dados.
- **NumPy** – Operações numéricas.
- **Matplotlib / Seaborn** – Visualização de dados.
- **Scikit-learn** – Implementação e avaliação de algoritmos de Machine Learning.

## Conceitos explorados

- Aprendizado supervisionado (*Supervised Learning*).
- Aprendizado não supervisionado (*Unsupervised Learning*).
- Classificação (*Classification*).
- Agrupamento (*Clustering*).
- Árvores de decisão (*Decision Trees*).
- Redes neurais artificiais (*MLP*).
- Random Forest.
- Análise exploratória de dados (*EDA*).
- Avaliação de modelos e métricas de desempenho.

## Objetivo

Este repositório reúne estudos e implementações práticas com o propósito de aprofundar conhecimentos em Ciência de Dados e Machine Learning, além de documentar minha evolução no desenvolvimento de soluções baseadas em dados.
